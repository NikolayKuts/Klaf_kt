# Transcript Vocabulary Analysis Nice-To-Have

> Temporary planning file. Delete this file after every item below is implemented,
> moved into permanent documentation, or explicitly rejected.

## Nice-To-Have Items

- Add an Ignored Words management screen to review and delete global ignored
  word/meaning rules.
- Show occurrence count for each detected word or phrase in the analyzed text.
- Sort results by occurrence count, confidence, or first appearance in the transcript.
- Preserve timestamps from SRT/VTT input and let the user jump back to the source moment.
- Add source-helper buttons after manual validation of subtitle/transcript websites.
- Support direct `.srt`, `.vtt`, and `.txt` file import.
- Save analysis history so the user can reopen previous transcript analysis results.
- Add filters for CEFR level, basic vocabulary, words only, phrases only, and uncertain items.
- Add filters by item status and result category, such as pending, added,
  ignored, new, and possible new meaning.
- Add semantic duplicate detection for Russian meanings, for example "price", "cost", and "fee" equivalents.
- Add batch creation into a selected deck after user review.
- Add server-side analysis when Klaf has a backend vocabulary database.
- Add transcript viewer navigation that scrolls to and highlights the selected
  item's occurrence in the source text.
- Reconcile vocabulary source card creation with existing duplicate-card
  prevention rules.
