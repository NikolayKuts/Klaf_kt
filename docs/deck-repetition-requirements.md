# Deck Repetition Requirements

- In Native → Foreign order, the native-side image holder stays disabled and shows a crossed-out eye.
- Turning to the foreign side in Native → Foreign order reveals the mnemonic image immediately. The user can still hide and reveal it manually.
- Foreign → Native order keeps its existing manual image reveal behavior.
- Tapping the displayed word does not play pronunciation.
- During repetition, a speaker button directly above the flip button plays foreign-word pronunciation. It is disabled on the native side.
